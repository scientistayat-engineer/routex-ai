Architecture

From keystroke to answer in four hops.

01

Client

Vanilla JS app on Firebase Hosting / Vercel. Auth + history via Firebase.

02

FastAPI

Serverless endpoint validates input and starts the CrewAI pipeline.

03

Router agent

Groq LLM returns category, confidence and reasoning. Rule-based fallback if it fails.

04

Specialist agent

Math, Teacher, Code, Translator, Summarizer or Writer produces the final answer. Every run is traced in LangSmith.

FAQ

What happens if the router is unsure?

A rule-based fallback classifier takes over, and the trace marks that step as “fallback”.

Can I choose the agent myself?

Yes. Use the mode dropdown in the console to skip routing and talk to one agent directly.

Where is my history stored?

In Firestore under your own account when signed in, otherwise only in this browser.

How do I inspect each run?

Every request is traced in LangSmith, with child runs for the router and the specialist agent.
